### 📝 Supported Markdown Rules

This panel explains the Markdown syntax supported by the custom, local parser used on this site.

### 1. Headings
To create headings, start a line with `#`, `##`, or `###` followed by a space.

# Title
## Section Title
### Subsection Title

### 2. Bold Text
Wrap your text in double asterisks to make it bold.

**This text is bold.**

### 3. Italic Text
Wrap your text in single asterisks to make it italicized.

*This text is italicized.*

### 4. Unordered Lists (Bullet Points)
To create bullet points, start a line with a dash `-` followed by a space.

- Item One
- Item Two
- Item Three

### 5. Links
To insert a hyperlink, put the link text in square brackets `[...]` and the URL in parentheses `(...)`.

[Click here for an example link](https://example.com)

### 6. Explicit Line Breaks
To force a hard line break within a block of text, add two spaces at the end of the line before pressing Enter.

This is the first line.  
This is the second line immediately below it.
